# Real-Time Object Detection using MobileNet SSD

## Project Overview
This project focuses on real-time object detection using the MobileNet SSD (Single Shot Detector) deep learning model. The system detects and identifies objects from live webcam video streams with high speed and efficiency.

The project uses OpenCV and a pre-trained MobileNet SSD model to recognize multiple objects such as persons, cars, bottles, chairs, dogs, cats, and many more in real time. Detected objects are highlighted using bounding boxes along with object labels and confidence scores.

MobileNet SSD is a lightweight deep learning architecture designed for fast object detection on low-power devices and real-time applications.

---

## Features
- Real-time object detection using webcam
- Fast and lightweight MobileNet SSD model
- Detection of multiple objects simultaneously
- Bounding boxes with labels and confidence scores
- Efficient performance for real-time processing
- Easy-to-use implementation using Python and OpenCV
